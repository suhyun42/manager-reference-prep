# JD manager reference brief

A static site containing Alicia’s previous-manager reference brief for JD. Includes the latest background and Why OpenAI / why this role section.

## Publish with GitHub Pages

1. Sign in to GitHub as suhyun42 and create a public repository named jd-reference.
2. Extract this ZIP. Upload index.html, .nojekyll, and README.md to the repository root and commit to main. Upload the extracted files, not the ZIP or its parent folder.
3. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch. Select main and / (root), then Save.
4. Open the published link shown in Settings > Pages when deployment finishes.

Expected URL after publication:
https://suhyun42.github.io/jd-reference/

This URL is not live until the repository is created, the files are uploaded, and Pages is enabled. The published site is publicly accessible.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Update
Replace index.html with your revised file and commit it to main. GitHub Pages will publish the update.
